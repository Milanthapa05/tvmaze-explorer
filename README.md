# TVMaze Explorer
A responsive AJAX-enabled web application that allows users to search TV shows 
using the TVMaze API.
## Features- Search TV shows- Fetch API with async/await- Dynamic DOM rendering- Responsive design- Loading spinner- Error handling- Cast information
## Technologies Used- HTML- CSS- JavaScript- TVMaze API
